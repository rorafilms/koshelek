Как этим пользоваться

1. План. Впишите, сколько и какого числа вам приходит (зарплата, аванс, подработка), и обязательные платежи: аренда, кредит, связь, коммуналка.

2. Траты. Купили что-то — нажмите «+», наберите сумму, выберите категорию. 5 секунд.

3. Следите за одним числом — «можно потратить сегодня». Уложились — завтра лимит станет больше. Превысили — меньше.

4. Цели. Откладывайте на мечту понемногу. Отложенное вычитается из лимита — так деньги не «растворяются».

Подсказки: листайте вкладки свайпом влево-вправо, а лишнюю трату смахните влево, чтобы удалить.

SMS банка — автоматически

Автоматизация на iPhone отправляет текст банковской SMS на указанный сервер. «Кошелёк» забирает её при открытии приложения и предлагает проверить операции. Записи хранятся в браузере на устройстве, но исходные SMS проходят через сервер. Убедитесь, что доверяете владельцу сервера и его правилам хранения. Не пересылайте SMS с одноразовыми кодами, паролями или полными данными карты.

Адрес
code
box
Как настроить на iPhone (5 минут)

1. Приложение «Команды» → вкладка «Автоматизация» → «+» → «Сообщение».

2. «Отправитель» — номер банка: Сбер — 900 (Т-Банк — Tinkoff/T-Bank, Альфа — Alfa-Bank, ВТБ — VTB). Выберите «Запускать немедленно» → «Далее» → «Новая пустая команда».

3. Добавьте действие «Получить содержимое URL». В поле URL вставьте Адрес (кнопка «Копировать» выше).

4. Нажмите стрелку «›» в действии: Метод — POST, Тело запроса — JSON. Добавьте 4 поля типа «Текст»:
• action = inbox_put
• code = значение «code» выше
• box = значение «box» выше
• sms = нажмите на значение → выберите переменную «Ввод быстрой команды» (это текст SMS).

5. Готово. Отправьте себе тест: дождитесь любой SMS от банка и откройте «Кошелёк» — появится окно с операциями.

Важно: у каждого человека свой «box» — его видно в настройках «Кошелька» на его телефоне.

Без настройки тоже можно: скопируйте SMS → «+» → «Из SMS».

Поделиться с близкими

Отправьте ссылку супруге или друзьям. Если GigaChat подключён, он подключится у них автоматически. У каждого будут свои данные — общий только советник.

Установить на iPhone

Откройте сайт в Safari → кнопка «Поделиться» → «На экран Домой». Приложение будет работать даже без интернета.
