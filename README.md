# Кошелёк — простой бюджет

Веб-приложение для учёта денег: доходы и обязательные платежи, траты по дням, календарь, цели-копилки и советник.
Работает на iPhone как обычное приложение, в том числе без интернета.

## Файлы

| Файл | Что это |
|---|---|
| `index.html` | само приложение |
| `manifest.webmanifest` | название и иконка для экрана «Домой» |
| `sw.js` | офлайн-режим |
| `icon-192.png`, `icon-512.png`, `apple-touch-icon.png` | иконки |

## Как выложить бесплатно

### Способ 1 — GitHub Pages
1. На github.com: **New repository** → имя `koshelek` → Public → Create.
2. **Add file → Upload files** → перетащите все файлы из архива → Commit.
3. **Settings → Pages** → Source: *Deploy from a branch*, Branch: `main`, папка `/ (root)` → Save.
4. Через 1–2 минуты сайт будет по адресу `https://ВАШ_ЛОГИН.github.io/koshelek/`.

### Способ 2 — Netlify Drop (без регистрации на GitHub)
1. Откройте app.netlify.com/drop.
2. Перетащите папку с файлами в окно.
3. Получите ссылку вида `https://что-то.netlify.app` (можно переименовать в настройках сайта).

## Установка на iPhone
Safari → откройте ссылку → «Поделиться» → **«На экран Домой»**.

## Данные
- План, операции, долги и цели хранятся в браузере на устройстве.
- При включённом импорте SMS банковские сообщения пересылаются автоматизацией iPhone на указанный в настройках сервер и обрабатываются там. Проверяйте, кому принадлежит сервер и как долго он хранит сообщения.
- Текст SMS может содержать чувствительные сведения. Не пересылайте сообщения с одноразовыми кодами, паролями или полными данными карты.
- Раз в месяц приложение напоминает сохранить копию. На новом телефоне: **⚙︎ → Восстановить из копии**. Проверьте количество записей и подтвердите замену.

## Советник
- **Встроенный** работает всегда: бесплатно, без интернета и регистраций. 8 готовых разборов по вашим цифрам.
- **GigaChat** — живой чат на любые вопросы. Нужен сервер-посредник: инструкция в архиве `koshelek-server.zip`.
  По умолчанию сервер получает вопросы и сводные суммы. Передачу заметок, остатков по картам и других подробностей можно включить в настройках советника.

## Обновление
После изменения приложения или его ресурсов запустите `node scripts/version-cache.mjs` и добавьте обновлённый `sw.js` в коммит. Версия вычисляется из файлов приложения. GitHub Actions проверяет её и запускает `node --test` для PR и перед публикацией в Yandex Cloud.
